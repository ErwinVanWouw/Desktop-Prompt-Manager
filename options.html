Manage your Prompts

The first 4 prompts come pre-configured for translators and text editors, but can be fully customized. Prompts 5 to 9 are empty by default with no shortcuts assigned, but you can customize them as needed. Enter your prompt in the fields below and assign a shortcut following the instructions at the bottom of this page.


You can trigger each prompt using the shortcut Ctrl+Shift+# (e.g. Ctrl+Shift+1 for Prompt 1). On a Mac use shortcut Command+Shift+#. Alternatively, customize the keyboard shortcuts according to the instructions below.


To set up keyboard shortcuts for this extension or adjust the existing ones, go to:

chrome://extensions/shortcuts
